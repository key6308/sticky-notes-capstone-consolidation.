# Sticky Notes UML Diagrams

These diagrams were re-rendered as visual UML diagrams for the Sticky Notes Application Part 1 submission.

## Included diagrams
- `use_case_diagram.png` / `.pdf` — User is the actor and initiates the Create, View, Update, and Delete interactions.
- `sequence_diagram.png` / `.pdf` — Shows the Create Note request flow between User, Browser, Django View, and Database.
- `class_diagram.png` / `.pdf` — Shows the StickyNote model and StickyNoteForm relationship.

The `.dot` files are editable Graphviz source files, and the `.txt` files are included as simple source/reference versions.
